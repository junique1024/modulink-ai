# 개발 이력 (성장의 폭)

| 회차 | 결과물 | 핵심 변화 |
|---|---|---|
| 1~2차시 | 집중 타이머(Streamlit), 자기소개·서비스 구상 페이지 | 바이브 코딩 첫 경험, 문제 정의(공장 관리자의 로봇 도입 검토 불편) |
| 3차시 | Next.js + Supabase 웹앱 | 조건 입력 → DB 모듈 중 최적 조합 추천 → 회수 기간 계산 → 저장 |
| 최종 | ModuLink-AI 최종본 | 말로 요청(규칙 기반 + Claude API) · 기본값 투명 표시 · 업무 대체율 · 누적 손익 그래프 · 안전·호환성 체크리스트와 PDF 리포트 · DB 장애 시 브라우저 저장 자동 전환 |

## 최종본에서 고친 약점
- 문장에 없는 값을 몰래 채우던 문제 → "기본값 사용"으로 분리 표시
- 예시를 연달아 실행하면 이전 값이 섞이던 문제 → 매번 기본값에서 출발
- 인건비 100% 절감 가정 → 업무 대체율 반영
- "1인당"을 인원으로 오인식 → 수정, 톤·km·억 단위 인식 추가
- 입력란에서 Enter를 누르면 추천 없이 저장되던 문제 → Enter = 추천
- 조건을 바꿔도 이전 결과가 남던 문제 → "다시 계산" 안내, 그 상태에선 저장 불가
- DB 오류 시 화면 전체가 멈추던 문제 → 3초 제한 + 브라우저 저장 자동 전환
- 서버리스 배포에서 로컬 파일 저장 불가 → 브라우저 저장으로 대체
- 같은 결과 중복 저장 → "저장됨 ✓"
