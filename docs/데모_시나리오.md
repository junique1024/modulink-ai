# 데모 시나리오 (발표 4분 중 시연 약 1분 30초)

> 모든 값은 시연용 예시 데이터(`더미데이터_모듈카탈로그.csv`) 기준. 기본값: 대체율 70%, 인건비 4,500만원

| 순서 | 동작 | 화면에 나오는 결과 | 말할 포인트 |
|---|---|---|---|
| 1 | 예시 ① 클릭: "하중 50kg 물품을 A에서 B로 80m 옮긴 뒤 외관 검사까지, 작업자 2명 대체" | B300 + A15 + V1, 도입비 7,187만원, 회수 1.3년(15개월) | "이렇게 이해했어요"와 "기본값 사용"이 따로 표시됨 → 무엇을 가정했는지 투명 |
| 2 | 근거 줄 가리키기 | 필요 적재 112kg → B100(100kg) 탈락, B300 선택 | 50kg인데 왜 중형? 로봇팔·센서 무게까지 계산하기 때문 = 시운전 단계 호환성 오류를 미리 차단 |
| 3 | 예시 ② 클릭: "200kg 부품 상자… 25kg 꺼내고 치수 정밀 검사, 2교대 2명" | B600 + A30 + V3로 조합이 바뀜, 회수 1.1년(13개월) | 조건이 바뀌면 조합·규격(A→B)이 자동으로 바뀜 |
| 4 | 대체율 슬라이더 70% → 40% → [다시 계산하기] | 회수 기간이 늘어남 | 보수적으로 잡아도 회수되는지 바로 확인 가능 |
| 5 | 체크리스트·[검토 리포트 인쇄·PDF] | 조합별 안전 검토 항목 | 참고용 항목이며 인증을 대신하지 않음 |
| 6 | [검토 기록 저장] | 기록 목록에 추가 | 여러 안을 저장해 비교 |

## 예상 질문 대비
- **AI가 틀리면?** 이해한 값을 전부 화면에 보여주고, 입력란에서 바로 고칠 수 있음. Claude API가 실패해도 규칙 기반으로 계속 동작
- **가격·사양 근거?** 시연용 예시 값. 실제 서비스는 모듈 제조사가 사양을 등록하는 구조(DB 테이블로 분리돼 있음)
- **ROI가 낙관적이지 않나?** 대체율(기본 70%)과 유지보수비(도입비의 8%/년), 설치비(15%)를 반영. 슬라이더로 즉시 보수적 시나리오 확인
- **안전 인증은?** 체크리스트는 검토 항목 안내이며 최종 판단은 전문가·인증기관
